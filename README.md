2. **마이링크 주소 생성 (1점)**

---

## 🚀 프로젝트 구조
```
projects/
└── mylink/                # 마이링크(MyLink) 전용 폴더
    ├── app/               # Next.js App Router (페이지 및 API 라우트)
    ├── src/               # 컴포넌트, 스타일, 유틸리티
    ├── public/            # 정적 파일
    ├── PRD.md             # 제품 요구사항 정의서
    ├── package.json       # 프로젝트 패키지 설정
    └── ...
```

## 🛠 기술 스택
- Framework: Next.js 16 (App Router)
- UI / Design: React 19, Tailwind CSS v4, shadcn/ui
- Language: TypeScript
- Deployment: Vercel
